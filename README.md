# 🛡️ CyberGuard – AI Cybersecurity Awareness Assistant

CyberGuard is an interactive, beginner-friendly web application built with Python and Streamlit. Designed to promote digital safety education, CyberGuard helps users detect phishing attempts, evaluate password strength, test their cybersecurity knowledge, and track past risk scans.

---

## ✨ Features

- 📧 Phishing & Link Analyzer: Scans suspicious emails, SMS messages, and website URLs for common scam indicators and urgent phrasing to provide instant threat scores.
- 🔑 Password Strength Advisor: Evaluates password complexity and delivers actionable tips to help create stronger passwords.
- 💡 Interactive Quiz & Chatbot: Tests digital literacy with interactive security quizzes and answers basic cybersecurity questions.
- 📜 History & Logs: Saves past security scans locally (via JSON/CSV) for quick reference.

---

## 🛠️ Tech Stack & Prerequisites

- Language: Python 3.9+
- UI Framework: Streamlit
- Testing: Pytest
- Data Persistence: JSON / CSV
